# Frontend

Next.js (App Router) client for the Company Knowledge Assistant. See the [repository root README](../README.md) for architecture, setup, and environment configuration — this app is not meant to run standalone; it talks to the FastAPI backend in `../backend`.

Local development (after the backend is running — see the root README):

```bash
npm install
npm run dev
```

`npm run lint` and `npm run build` are the same checks run in [Tests & linting](../README.md#tests--linting).
